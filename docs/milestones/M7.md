# M7 — Pixels: step records

Step records, moved from [milestones.md](../milestones.md) on 2026-10-08, which keeps the synopsis.

Scoped 2026-10-08: [docs/21](../21-pixels.md) holds the decisions (client-owned buffers, Flatland's credits on 03 §4's records, `displayd` and `winsrv` split as Fuchsia's coordinator and compositor, write-combining physical VMOs, HID input records with the held set, rio's per-app attach, v1's VRR/tearing/HDR fields carried but not driven), the contradictions it settles, and the order. Tracing comes first (docs/20 §9), as placed on 2026-10-07; it moves PMU sampling here from M14. Decided with the user: the exit is pixels only, `lib/vx-text` goes to the editor (M6's formatting becomes `lib/vx-fmt`), the terminal is an M7 step.
