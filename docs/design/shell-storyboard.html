From Tracker and Deskbar to a desktop that remembers

One person's day on the shell as it is specified. They write code, keep a large music library, and play games in the evening, on a wide monitor. The rule under every frame is mouse first, with keys and scripts for everything. Each frame is drawn in the default Neon Tab theme and sets what BeOS did beside what Todhchai keeps, changes or adds. The additions from Scott Jenson's talks arrive as options beside stacking windows, and as prototypes on the hosted SDK before M8 makes any of them a default.

Kept from BeOS

  • The yellow tab, now the amber neon tab, drawn by the server, with Be's close box at its left and zoom box at its right
  • Icons in Be's projection, lit from the upper left, now neon wireframes
  • Tracker: attribute columns, queries as folders, live query windows
  • Deskbar and its replicant tray
  • Workspaces with their own resolution and wallpaper
  • Translators that teach every app a format
  • People and Mail as files with attributes

Changed

  • Replicants run out of process, as view tokens; a crash takes down only the replicant
  • hey scripting over typed schemas, plus intent streams with claim and decline
  • Queries v2: typed literals, ranges, order by, resumable live queries
  • Deskbar shows CPU, GPU, audio latency and frame pacing
  • Haiku's stack-and-tile tabs; tiling is optional per workspace

Added (Jenson, 2026-10-10)

  • Press selects, release raises
  • Middle truncation of names, keeping the extension
  • A focus area with a live periphery
  • Snap by drag, tile by chord: mouse first, with your own key chords
  • Stashing to a compact size class
  • The drawer, provenance, and an opt-in attention history
  • Proposals, never rearrangement, and the rules for a model in the middle (2026-10-11)

Icons: Be's projection, in Neon Tab's cues

Drawn as Be drew them: 2:1 isometric, the object's front turned to the lower left, lit from the upper left. The top face is brightest (40% of the edge colour over bg.0), the front 22%, the side 9%. Edges are a 1 px neon wireframe in the kind's colour: cyan for places, magenta for queries and capture, amber for replicants and mail, ink for documents, whose type colour is the emblem. Cuts are chamfered like the tab, and only what is selected or dragged glows. The accessibility theme thickens the edges and drops the glow. Shown at 64, 32 and 16 px.

BeOS

BFS made typed attributes, indices and live queries part of the file system, and Tracker showed a saved query as a folder with attribute columns. But wildcard queries were slow, the index never back-filled, and monitoring was lost at reboot.

Todhchai

Taisce keeps the model and fixes those flaws. Its query language is a superset of BFS's syntax with typed literals, ranges and order by. Live queries stream added, removed and changed rows carrying a journal seq, so they resume after a crash. Tracker lists millions of entries asynchronously, and names elide in the middle by default.

BeOS

You placed a window by dragging its tab, and there was no snapping. Haiku later added stack-and-tile with a modifier held while dragging. Keyboard shortcuts belonged to each app, and you couldn't bind your own window placements.

Todhchai

Mouse first: anything you can do, you can do with the pointer, but not always by the same route as a key. Dragging to an edge or corner snaps, as on Windows and KDE. A tiling user binds their own chords for the same placements and more. Chords are registered with Radharc's shortcuts service and act through windows, so the chord map is a file and a script can do whatever a chord does. Chords you add need no pointer twin.

The evolution, in one line

BeOS made the file system something you could ask questions of. Todhchai keeps that, makes the shell remember what you gathered, where things came from and what you did, and keeps additions beside what works: stacking windows, workspaces and the classic clipboard all remain.

When it arrives

  1. Prototypes on the hosted SDK (Linux, Wayland): focus area, stashing, drawer, provenance, history, each opt-in
  2. M6: Tracker, Deskbar, Terminal, Inspector, Preferences, the router, the keyring, privileged services
  3. M8: on the reference machine; a structural idea becomes a default only once it has proved itself

Still open

Whether a model ships at all. The rules for one are decided (frames 12 and 13): it reads what Taisce and the drawer already keep, writes only derived: proposals you can undo, runs confined, and is off until turned on. It never drives the system. A hosted prototype must beat the arithmetic tier first.
