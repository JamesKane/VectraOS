# Desktop storyboard

The sources of the [VectraOS Desktop Storyboard](https://claude.ai/artifact/BcQQLDod1qqmgwVzabeTPX),
copied on 2026-10-15. The canvas is the live copy; these files are a
record of it. Each `.dc.html` is one 1920×1080 frame, and `canvas.json`
lays them out with their captions. They render inside the canvas, which
supplies `support.js`.

The look and its status are in D24 (`docs/decisions/`); architecture §7
describes the desktop they draw.
