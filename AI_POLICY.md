# AI policy

AI assistance is permitted. Use whatever tools help you: completion, chat, agents.

You are the author. Whatever you submit is yours, however it was written:

1. **Review it.** Read every line before you submit it. Don't send code you haven't read.
2. **Make sure it's correct.** It builds, passes `./build check`, and is tested to the same standard as any other change. You have to be able to explain it and defend it in review. "The model wrote it" is not an answer.
3. **Make sure you can license it.** You submit it under BSD-3-Clause, as with any contribution. Don't submit output that copies someone else's code. Third-party code goes under `third_party/` and gets reviewed like any other vendored code.
4. **Put a person behind it.** Every pull request, issue and bug report has a human who answers for it. Reports from AI tools, security scanners included, need a human who checked them and can show how to reproduce them.

Saying that a tool helped is welcome but not required. A commit trailer such as `Assisted-by:` or `Co-Authored-By:` is fine.

Contributions are judged on what they are, not on how they were made. Work that is unreviewed, wrong or can't be explained gets closed, whoever or whatever wrote it.
