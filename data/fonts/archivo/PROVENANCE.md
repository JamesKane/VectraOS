# Archivo (Omnibus-Type)

Third-party data under the SIL Open Font License 1.1 (`OFL.txt`, beside
this file), never relabelled. Platinum Indigo's type (D24): the
storyboard's kit frame names it, Archivo for display, running text and
the UI's labels. Static instances, since the OpenType reader has no
variations: google/fonts carries only the variable font, so these come
from the foundry's own repository. The UI's width 92 has no instance;
SemiCondensed (87.5) is the nearest.
